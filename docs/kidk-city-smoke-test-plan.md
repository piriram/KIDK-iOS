# KIDK 키득시티 SpriteKit 스모크 테스트 계획서

작성일: 2026-03-04 (Asia/Seoul)
대상: `KIDK/Presentation/View/Mission/KidkCity/KIDKCityViewController.swift`
목표: "지금 당장 동작하는지"를 짧은 시간 내 확인 (정밀 QA 아님)

---

## 1) 스모크 테스트 목적

- 앱 크래시 없이 키득시티 진입/노출이 가능한지
- SpriteKit 씬이 정상 표시되는지
- 핵심 인터랙션(학교 탭/마트 잠금 토스트/시트 오픈)이 작동하는지
- 기기 사이즈 차이에서 치명적 UI 깨짐이 없는지

성공 기준: **핵심 경로가 막힘 없이 1회 이상 통과**

---

## 2) 범위 (In/Out)

### In Scope

1. 로그인(또는 테스트 계정 진입) → 미션 탭 → 키득시티 진입
2. 배경/건물/캐릭터 노출
3. 학교 건물 탭 → 미션 선택 시트 표시
4. 마트(잠금 상태) 탭 → 잠금 안내 토스트 표시
5. 홈 버튼 탭 → 이전 화면 복귀

### Out of Scope

- 픽셀 단위 위치 정합 정밀 검증
- 애니메이션 프레임 드랍 정량 분석
- 모든 기기/OS 전체 회귀
- 서버 연동 상세 시나리오(마트 오픈 이후 기능)

---

## 3) 테스트 환경

- 브랜치: 현재 작업 브랜치
- 빌드: Debug
- 실행 타겟(최소 3종):
  - 소형: iPhone SE 계열
  - 표준: iPhone 15/16 일반형
  - 대형: iPhone 15/16 Pro Max
- 화면 방향: 세로 고정(프로젝트 정책 준수)

---

## 4) 실행 절차 (10~20분)

### Step 1. 빌드/실행 확인

- 앱 실행 시 크래시 없음
- 로그인/테스트 유저 진입 가능

### Step 2. 키득시티 진입

- 미션 화면에서 “키득시티로 놀러가기” 버튼 탭
- 키득시티 화면 전환 성공

### Step 3. 초기 렌더 확인

- 배경 지도 표시
- 학교/마트/캐릭터 표시
- HUD(게이지, 레벨, 버튼) 표시
- 심각한 레이아웃 깨짐/겹침 없음

### Step 4. 인터랙션 확인

- 학교 탭 시 미션 선택 시트 노출
- 시트 닫기/이전 동작 정상
- 마트(잠김) 탭 시 잠금 토스트 노출
- 홈 버튼 탭 시 이전 화면 복귀

### Step 5. 기기 3종 빠른 재확인

- 위 Step 2~4 핵심 경로만 반복
- 기기별로 "탭 불가", "노드 미표시", "즉시 크래시" 여부 확인

---

## 5) 체크리스트

- [ ] 키득시티 진입 시 크래시 없음
- [ ] SKScene 정상 노출 (배경/건물/캐릭터)
- [ ] 학교 탭 시 시트 오픈
- [ ] 마트 잠금 탭 시 토스트 노출
- [ ] 홈 버튼 복귀 정상
- [ ] 소형/표준/대형 기기에서 치명 이슈 없음

---

## 6) 판정 기준

### PASS

- 모든 필수 체크리스트 완료
- 치명 이슈(Crash, 진입 불가, 터치 완전 불능) 없음

### FAIL

- 필수 경로 중 1개라도 실패
- 크래시 또는 키득시티 미노출 발생

---

## 7) 실패 시 즉시 조치

1. 재현 스텝 3줄로 고정 기록
2. 기기/OS/브랜치/커밋 해시 기록
3. 스크린샷 1장 + 콘솔 오류 1개 첨부
4. 이슈 분류:
   - A: 진입/크래시 (즉시 핫픽스)
   - B: 터치/시트 불능 (우선 수정)
   - C: 경미 UI 어긋남 (후속 정밀 QA로 이관)
