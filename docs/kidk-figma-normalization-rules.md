# KIDK Figma 스크린샷 정규화 & 비교 규칙

작성일: 2026-03-01
적용 브랜치: `Feat/kidk-figma-hybrid`

## 1) 비교 기준 디바이스
- 기준 디바이스: **iPhone 16 Pro**
- 기준 해상도/비율: 시뮬레이터 캡처 원본 유지
- 상태바/노치 포함 캡처를 기본으로 사용

## 2) Figma 스크린샷 정규화 규칙
- `stretch` 금지 (왜곡 금지)
- `contain + padding` 방식으로 캔버스만 기준 크기에 맞춤
- 상단 정렬 기준 통일(노치/상단 여백 포함)
- 좌우 중앙 정렬 통일
- 원본 파일은 보존, 정규화본은 별도 폴더 저장

## 3) 비교 우선순위
### 1순위: 구조 동일성 (필수)
- 섹션 순서
- 정보 계층 (제목/본문/보조텍스트)
- CTA 위치와 흐름
- 카드 그룹 구조

### 2순위: 스타일 유사성 (보정)
- 간격/패딩
- 컬러 톤
- 라운드/보더/그림자
- 배지/아이콘 모양

## 4) 허용 오차(초기)
- 간격/패딩: ±4~8pt
- 폰트 사이즈: ±1 step
- 아이콘: 동일 톤 fallback 허용(원본 에셋 수급 전)

## 5) 누락 에셋 정책
- 누락 시 SF Symbol/placeholder로 우선 매칭
- 문서에 아래 항목 반드시 갱신
  - 필요한 Asset key
  - 사용 화면
  - 대체(fallback) 방식

## 6) 반복 루프
1. 목표 화면 선정 (6~8개)
2. Figma 정규화본 생성
3. 시뮬레이터 캡처
4. 나란히 비교 이미지 + diff 이미지 생성
5. 차이 체크리스트 작성
6. 수정 후 재캡처 (최소 2회)
7. Debug 빌드 확인
