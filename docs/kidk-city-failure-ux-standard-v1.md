# KIDK City 실패 분기 UI 메시지 표준화 v1

작성일: 2026-03-10
범위: KIDK City (미션 승인/이체/연출)

## 1) 목적

- 실패 원인별 사용자 메시지를 일관되게 제공
- 재시도 가능/불가를 명확히 구분
- 기술 에러를 그대로 노출하지 않고 행동 가능한 문구로 변환

## 2) 분류 체계

### A. 승인 실패 (verification_approved 실패)
- 토스트: `인증 확인에 실패했어요. 다시 시도해 주세요.`
- 보조문구: `네트워크 상태를 확인한 뒤 다시 시도하면 좋아요.`
- 버튼: `다시 시도`
- 정책: **재시도 가능**

### B. 이체 실패 (reward_transferred 실패)
- 토스트: `용돈 이체에 실패했어요. 잠시 후 다시 시도해 주세요.`
- 보조문구: `문제가 계속되면 보호자에게 알려주세요.`
- 버튼: `다시 시도`
- 정책: **재시도 가능 / idempotencyKey 유지**

### C. 연출 실패 (city_progress_updated 연출만 실패)
- 토스트: `도시 반영 연출이 일시적으로 지연됐어요.`
- 보조문구: `보상은 정상 반영되었어요.`
- 버튼: 없음 (자동 복구)
- 정책: **비즈니스 성공, UI만 복구**

### D. 중복 이벤트 차단
- 토스트: 노출 없음
- 로그: `Skip duplicated mission completion event`
- 정책: **idempotencyKey 기준 무시**

## 3) UX 규칙

- 실패 토스트 노출 시간: 1.2~1.5초
- 한 번에 하나의 실패 메시지만 표시
- 같은 실패 연속 발생 시 메시지 중복 표시 방지(디바운스)
- 재시도 버튼은 승인/이체 실패에만 제공
