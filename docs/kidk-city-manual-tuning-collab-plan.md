# KIDK 키득시티 수동 튜닝 협업 계획서 (사용자 조정 + 에이전트 반영)

작성일: 2026-03-04 (Asia/Seoul)
대상: KIDKCity SpriteKit 맵(배경/건물 위치 정합)

---

## 1) 목적

기기별 화면 차이로 발생하는 배경-건물 어긋남을 **가장 빠르게** 맞추기 위해,

- 사용자가 앱 내 디버그 패널로 직접 시각 조정하고,
- 에이전트가 전달받은 값을 구조화/코드 반영/검증

하는 협업 방식으로 정합을 완료한다.

---

## 1-1) 기기 크기별 배경 표시 정책 (추가 반영)

핵심 사실:

- 배경 원본 파일 자체는 동일하지만,
- iPhone 기기별 화면 비율/해상도 차이로 **배경의 표시 크기와 보이는 영역(크롭 포함)** 이 달라질 수 있다.

정책:

1. 배경은 `contentMode` 정책(예: aspectFill) 기준으로 렌더링한다.
2. 건물 좌표는 화면 절대값이 아니라 `xRatio/yRatio`로 저장한다.
3. 런타임에서 "배경 실제 표시 영역(display rect)"을 계산해 건물 위치를 변환한다.
4. 즉, 기기별 차이는 표시영역 계산이 흡수하고, 좌표 데이터는 공통값을 우선 사용한다.

검증 포인트:

- 소형/표준/대형 기기에서 동일 건물이 배경의 같은 지점에 붙어 보이는지 확인
- `aspectFill` 크롭이 있어도 건물 기준점이 드리프트하지 않는지 확인

## 2) 협업 방식 (핵심)

### 사용자 역할

- 실제 디바이스/시뮬레이터에서 화면을 보며 조정
- "어디가 맞다/안 맞다"를 즉시 판단
- 최종 수치(JSON 또는 텍스트) 전달

### 에이전트 역할

- 디버그 조정 UI 제공
- 전달받은 수치를 데이터 파일에 반영
- SpriteKit 좌표 계산 로직 정리
- 스모크 테스트 및 결과 문서화

---

## 3) 구현 범위

### 3-1. 디버그 조정 패널 추가

조정 항목:

1. 배경
   - `bgScale` (예: 0.8 ~ 1.4)
   - `bgOffsetX`, `bgOffsetY`
2. 건물(학교/마트 등)
   - `xRatio`, `yRatio` (0~1)
   - 필요 시 `scale`
3. 공통
   - 리셋(기본값 복원)
   - 현재값 복사/내보내기(JSON 문자열)

노출 조건:

- Debug 빌드에서만 표시
- 토글 방식(예: 3손가락 탭 또는 숨김 버튼)

### 3-2. 저장 포맷 표준화

```json
{
  "map": {
    "id": "kidk_city_v1",
    "bgScale": 1.0,
    "bgOffsetX": 0,
    "bgOffsetY": 0
  },
  "buildings": {
    "school": { "xRatio": 0.52, "yRatio": 0.61, "scale": 1.0 },
    "mart":   { "xRatio": 0.81, "yRatio": 0.34, "scale": 1.0 }
  }
}
```

전달 방식:

- 사용자가 디버그 패널에서 JSON 복사
- 채팅으로 붙여넣기 전달

### 3-3. 반영 대상

- `KIDKCityViewController.swift` 내 `KidkCityScene` 배치 로직
- (선택) 별도 설정 파일로 분리: `KIDK/Resource/Config/kidk_city_layout.json`

1. 키득시티 진입
