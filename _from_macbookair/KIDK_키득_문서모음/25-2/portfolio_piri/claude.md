## 💪 완벽주의 극복 전략

### 80% 룰 (The 80% Rule)

> **80% 완성도로 일단 넘어가면, 100%보다 5배 빠르게 끝낸다**

#### 적용 방법:

1. **타이머 설정**: 한 페이지당 최대 30분
   - 30분 지나면 무조건 다음 페이지로
   - 나중에 시간 남으면 돌아오기 (안 남아도 OK)

2. **3초 룰**: 문장 고민은 3초까지
   - Codex가 준 옵션 중 3초 안에 선택
   - "이게 나을까 저게 나을까" 고민 시작하면 → 첫 번째 옵션 선택

3. **완벽은 적이다 마인드셋**:
   - ✅ "멘토님께 보낼 수 있는 수준" = OK
   - ❌ "완벽한 문장" = 영원히 완성 못함
   - **중요**: 멘토님은 완벽한 포폴이 아니라 **나의 성장**을 보고 싶어 하심

4. **진도 우선주의**:
   - 10페이지 중 8페이지 완성 > 1페이지만 완벽하게
   - 멘토님께는 "작업 중" 버전이라도 빨리 보여드리는 게 중요

### 우울증/ADHD 대응 전략

#### ADHD 집중력 관리:
- **포모도로**: 25분 작업 + 5분 휴식
- **작은 성취감**: 페이지 하나 끝날 때마다 체크리스트에 ✅ 표시
- **보상**: 2페이지 완성하면 좋아하는 간식/영상 보기

#### 우울증 에너지 관리:
- **좋은 날 몰아서**: 컨디션 좋은 날 3~4페이지 몰아치기
- **나쁜 날은 쉬기**: 억지로 하지 말고 쉬어도 OK
- **자책 금지**: "오늘 못했어도 내일 하면 됨"

## 📝 마크다운 → HTML 변환 규칙

**portfolio.md → index.html 변환 시 적용되는 규칙**

### 기본 변환 규칙

| 마크다운 문법 | HTML 변환 | 설명 |
|-------------|----------|------|
| `` `텍스트` `` | `<span class="text-bold">텍스트</span>` | **강조/볼드** (가장 많이 사용!) |
| `**텍스트**` | `<span class="text-bold">텍스트</span>` | 볼드체 |
| `*텍스트*` | `<em>텍스트</em>` | 이탤릭체 |
| `> 인용` | `<blockquote>인용</blockquote>` | 인용구 |

**⚠️ 중요**: 이 포트폴리오에서 백틱(`)은 코드가 아니라 **강조/볼드**를 의미합니다!

### Claude에게 요청하는 방법

**HTML 업데이트할 때 항상 이렇게 요청:**

```
"portfolio.md의 Page X를 index.html에 반영해줘.
백틱(`텍스트`)은 <span class="text-bold">로 변환."
```

**예시:**
```markdown
# portfolio.md
Solution: 사용자가 남긴 서핑 기록과 기상청 데이터를 분석하여
`나에게 맞는 파도 수치`를 파악할 수 있도록 도와준다.
```

↓ 변환 ↓

```html
<!-- index.html -->
Solution: 사용자가 남긴 서핑 기록과 기상청 데이터를 분석하여
<span class="text-bold">나에게 맞는 파도 수치</span>를 파악할 수 있도록 도와준다.
```

### 주의사항

- ⚠️ **매번 명시하기**: Claude에게 변환 규칙을 매번 알려줘야 함!
- ⚠️ **일관성 유지**: 모든 프로젝트에 동일한 규칙 적용
- ✅ **검증**: HTML 업데이트 후 브라우저에서 볼드 스타일이 잘 적용되는지 확인

### "이 문장이 별로인 것 같아... 더 고쳐야 할까?"

→ **NO.** 3초 안에 선택. 사실 다 비슷비슷함. 고민하는 시간에 다음 페이지 갈 수 있음.

### "이 페이지는 좀 더 시간을 들여야 할 것 같아..."
→ **NO.** 타이머 30분 지나면 무조건 넘어가기. 나중에 시간 남으면 돌아오기 (안 남아도 OK).
