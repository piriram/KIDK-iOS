## ⚙️ 1분 설정 가이드

### Step 1: 핵심구현 체크리스트 (맨 왼쪽, 프리뷰)

```
1. 핵심구현_체크리스트.md 열기
2. Cmd + Shift + V (마크다운 프리뷰로 열기)
```

**결과:**
- 항상 체크리스트가 보임
- 편집 불가 (프리뷰만)
- 스크롤하면서 확인 가능

---

### Step 2: projects/dosurf.md (중앙, 수정+프리뷰)

```
3. Cmd + \ (에디터 세로 분할)
4. projects/dosurf.md 열기
5. Cmd + K, V (사이드에 프리뷰 열기)
```

**결과:**
- 왼쪽: dosurf.md 편집 모드
- 오른쪽: dosurf.md 프리뷰 (실시간 렌더링)
- 동시에 수정하면서 결과 확인 가능

---

### Step 3: portfolio.md (오른쪽, 작업)

```
6. Cmd + \ (에디터 세로 분할)
7. portfolio.md 열기
```

**결과:**
- 실제 작업 파일
- 여기서 텍스트 수정

---

### Step 4: 터미널 스플릿 (아래)

```
8. Cmd + J (터미널 열기, 이미 되어있으면 스킵)
9. Cmd + \ (터미널 스플릿)
   - 왼쪽 터미널: Claude Code
   - 오른쪽 터미널: Codex
```

**결과:**
- 왼쪽: Claude Code (질문, 확인)
- 오른쪽: Codex (검수, 개선)

---

### Step 5: 마무리 정리

```
10. Cmd + B (사이드바 숨기기 - 공간 확보)
11. 터미널 높이 조절 (경계선 드래그, 40% 정도)
12. 에디터 폭 조절 (체크리스트 20%, dosurf 40%, portfolio 40%)
```

**완성!** 🎉

## 🎯 작업 흐름

### 일반 페이지 작업 (Page 1-3, 5, 7, 9)

```
1. 왼쪽 (체크리스트): 일반적인 기준 확인
2. 오른쪽 (portfolio.md): 텍스트 수정
3. 아래 (Codex): "이 프로필 섹션 개선해줘"

```

**체크리스트는 참고만, 주로 portfolio.md와 Codex 사이에서 작업**

```

   - 필요한 부분 복사

3. 오른쪽 (portfolio.md):
   - dosurf.md에서 복사한 텍스트 붙여넣기
   - 수정 작업

4. 아래 (Codex):
   "dosurf.md 보고 portfolio.md에 핵심구현 개선해줘.

5. 왼쪽 (Claude Code):
   "이거 체크리스트 기준 맞아?"
```

## ⌨️ 필수 단축키 모음

### 에디터 관리

| 단축키 | 기능 |
|--------|------|
| `Cmd + \` | 에디터 세로 분할 |
| `Cmd + K, Cmd + \` | 에디터 가로 분할 |
| `Cmd + W` | 현재 에디터 닫기 |
| `Cmd + K, W` | 모든 에디터 닫기 |

### 마크다운 프리뷰

| 단축키 | 기능 |
|--------|------|
| `Cmd + Shift + V` | 프리뷰로 열기 |
| `Cmd + K, V` | 사이드에 프리뷰 열기 |

### 에디터 이동

| 단축키 | 기능 |
|--------|------|
| `Cmd + 1/2/3/4` | 1/2/3/4번째 에디터로 이동 |
| `Cmd + K, Cmd + ←/→` | 에디터 그룹 간 이동 |

### 터미널 관리

| 단축키 | 기능 |
|--------|------|
| `Cmd + J` | 터미널 토글 (열기/닫기) |
| `Ctrl + `` | 터미널 포커스 |
| `Cmd + \` | 터미널 스플릿 |
| `Option + Cmd + ←/→` | 터미널 간 이동 |

### 화면 정리

| 단축키 | 기능 |
|--------|------|
| `Cmd + B` | 사이드바 토글 |
| `Cmd + K, Z` | Zen Mode (초집중) |
| `Esc Esc` | Zen Mode 종료 |

## 💡 팁 & 트릭

### 1. 에디터 크기 조절

**마우스로:**
- 에디터 경계선 드래그

**키보드로:**
- `Cmd + K, Cmd + ←/→`: 에디터 그룹 크기 조절
- `Option` 누르고 드래그: 미세 조정

### 2. 터미널 높이 최적화

**작업 단계별:**
- 편집 중: 30% (에디터 넓게)
- 검수 중: 50% (AI 대화 크게)
- 완료 후: 20% (결과만 보기)

**빠른 조절:**
- 터미널 경계선 더블클릭: 최대화/복원

### 3. 탭 관리

**너무 많은 탭 방지:**
```json
// settings.json
{
  "workbench.editor.limit.enabled": true,
  "workbench.editor.limit.value": 5
}
```

**현재 탭만 유지:**
- `Cmd + K, W`: 다른 탭 모두 닫기
- `Cmd + K, Cmd + W`: 모든 탭 닫기

### 4. 프리뷰 스크롤 동기화

**dosurf.md 편집과 프리뷰 함께 스크롤:**
- 프리뷰 창에서 오른쪽 상단 🔗 아이콘 클릭
- "Scroll Preview with Editor" 활성화

## ⚙️ 추천 VSCode 설정

### settings.json 최적화

```json
{
  // 에디터
  "editor.minimap.enabled": false,
  "editor.lineHeight": 1.6,
  "editor.fontSize": 14,

  // 터미널
  "terminal.integrated.fontSize": 13,
  "terminal.integrated.defaultProfile.osx": "zsh",

  // 탭 제한
  "workbench.editor.limit.enabled": true,
  "workbench.editor.limit.value": 5,

  // 자동 저장
  "files.autoSave": "afterDelay",
  "files.autoSaveDelay": 1000,

  // 마크다운 프리뷰
  "markdown.preview.fontSize": 14,
  "markdown.preview.lineHeight": 1.6,

  // 사이드바
  "workbench.sideBar.location": "left",
  "workbench.statusBar.visible": true,

  // 집중 모드
  "zenMode.centerLayout": false,
  "zenMode.fullScreen": false,
  "zenMode.hideLineNumbers": false
}
```

**설정 방법:**
1. `Cmd + ,` (설정 열기)
2. 우측 상단 `{}` 아이콘 (JSON 편집)
3. 위 설정 복사/붙여넣기

## 🚨 문제 해결

### Q1: 에디터가 너무 작아요!

**해결:**
```
1. Cmd + B (사이드바 숨김)
2. 터미널 높이 줄이기 (30%로)
3. 에디터 폭 조절
   - 체크리스트: 15%
   - dosurf: 35%
   - portfolio: 50%
```

### Q2: 프리뷰가 안 보여요!

**해결:**
```
1. 마크다운 파일인지 확인 (.md)
2. Cmd + Shift + V 다시 시도
3. 또는 Cmd + K, V (사이드 프리뷰)
```

### Q3: 터미널 스플릿이 안 돼요!

**해결:**
```
1. 터미널 클릭 (포커스)
2. Cmd + \ 누르기
3. 또는 터미널 우측 상단 "+" 옆 분할 아이콘 클릭
```

### Q4: 화면이 너무 복잡해요! (ADHD)

**단순화:**
```
Option 1: 2분할만
┌──────────────────────────┐
│ portfolio.md │ 체크리스트│
├──────────────────────────┤
│ Claude Code  │ Codex     │
└──────────────────────────┘

Option 2: 필요할 때만 분할
- 기본: portfolio.md만
- 핵심구현 시: 체크리스트 추가 (Cmd+\)
- 참고 필요 시: dosurf.md 열기
```
